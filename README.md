⚡ Wizarding World TV 📺

Welcome, witches, wizards, and Muggles, to Wizarding World TV!

This is a magical, fan-made frontend directory designed to help fans discover legitimate places to stream, watch, and explore Harry Potter and Fantastic Beasts content across various networks and platforms.

Whether you're looking for the right streaming service or managing the database via the secret Admin Dashboard, this project brings the magic to your browser. ✨

🔮 Features

🎬 Magical Movie Directory: Browse the complete collection of Wizarding World films. Filter by series (Harry Potter or Fantastic Beasts) or use the search bar to find exactly what you're looking for.

📡 Channel & Streaming Guide: Discover international TV networks and streaming platforms currently broadcasting the magic.

⚙️ Secret Admin Dashboard: A built-in Content Management System (CMS) allowing authorized users to add, edit, and delete movie entries (currently features visually simulated CRUD operations for frontend demonstration).

🌙 Thematic UI: A dark, sleek, and responsive design utilizing the iconic Wizarding World gold (#d6b66c) and deep night sky hues.

🛠️ Tech Stack

This project is built using lightweight, vanilla web technologies—no wands (or complex build tools) required!

HTML5: Semantic structure.

CSS3: Vanilla styling, CSS Grid/Flexbox, and responsive media queries.

JavaScript (ES6): DOM manipulation, Fetch API for asynchronous data loading, and dynamic view toggling.

🚀 Getting Started

Want to cast this spell on your local machine? Follow these simple steps:

1. Clone the Repository

Open your terminal and run:

git clone https://github.com/YOUR-USERNAME/wizarding-world-tv.git
cd wizarding-world-tv


2. Launch the Application

Since this project uses modern JavaScript fetch() calls, it's best to run it through a local web server to avoid CORS (Cross-Origin) issues.

Using VS Code: Install the Live Server extension, right-click index.html, and select "Open with Live Server".

Using Node/NPM: Run npx serve . in the project directory.

3. About the Backend API

By default, the application looks for a local backend at http://127.0.0.1:5000/api.

If the backend is not running, the application has built-in fallback mock data so you can still view the beautiful UI and test the Admin Dashboard visually!
